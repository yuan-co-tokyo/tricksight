# T12-2c / T12-2d 履歴の骨格・現在値表示

2026-10-06。T12-2b実機通過を受け、履歴詳細の任意表示として実装。検収待ち、T12-2eの負荷・公開判定は未着手。

## 実装

所有者スコープの履歴取得と既存の署名URLを使う。サーバーの `HistoryVideoPlayback` が製品フラグを判定し、OFF/対象外では従来と同じnative videoのサーバーマークアップを返す。ONの対象者だけClientプレーヤーを表示し、表示用ライブラリは「骨格と数値を表示」を押した後に読み込む。モデルとWorkerは取得後の別タップ「計測を開始」まで起動しない。通常動画のsrc、再生位置は取得・計測・失敗・終了で置き換えない。

透明canvasに骨格を描き、下段に今回の左右膝平均角と腰相対高さ、再生/計測時刻を表示。native controls、再生速度、±0.1秒（押すと一時停止）、keyboard操作を提供。320pxは1列、操作は折り返し・44px以上。数値は毎フレーム読み上げず、準備状態/間引いた処理枚数だけを通知する。成功/失敗や成績ではない注意書きは常設。

保存済みカードは登録時の集約値のまま。今回の値は保存・履歴比較に混ぜず、計測保存APIも呼ばない。取得は100MiB・120秒、推論は3〜20秒の素材・120秒。型/長さ/非対応/品質不足の失敗でも動画と他の履歴操作を残す。

「骨格を隠す」は列を残した表示切替、「表示を終了」はWorker/Blob/非表示video/canvasを破棄する。表示videoは通常再生用として残す。pagehide、bfcache復帰、タブ非表示、unmount、URL変更、videoエラーでも破棄し、自動再起動しない。取得401/403/404（権限・期限切れ・削除相当）は本文を出さず、再読み込みを案内する。再読み込みで既存の認証・所有権チェックを再度受ける。すでに発行されたURLの権限を別端末の削除後に即失効させる新APIは設けていない。

### 部分骨格と数値の説明

T12-2bの実機値（24点描画、膝/腰に値あり、PARTIAL_SKELETON）は正常。骨格の9点は省略されていても、2指標に必要な部位が揃っていれば値を表示できる。画面には「骨格の一部を検出できません。検出できた部分だけを表示しています。」を表示し、数値欠測とは区別する。指標に必要な部位が不足する場合だけ該当値を「—」にする。全体quality不足なら全数値を「—」にし、骨格だけの表示であると説明する。内部の英字コード・Worker・点数・JSONは製品画面に出さない。

## 保存状態と今回の表示

|保存/動画状態|今回の入口・表示|確認|
|---|---|---|
|COMPLETED|任意取得→計測。即時の骨格表示とはしない|サーバー分岐/入口テスト|
|UNASSESSABLE|「検出できた部分を見る」。今回も全体不足なら骨格のみ・全数値—|サーバー分岐＋ブラウザーpartial|
|FAILED / TIMED_OUT / CANCELED|保存カードを変えず今回の計測は任意に試せる|各状態のサーバー/入口テスト|
|MISSING（古い未計測）|保存カードは未計測のまま、現行形式/容量/長さ内で任意計測|サーバー/入口＋長さ制約テスト|
|未upload・再生失敗・動画なし/削除・署名失敗|開始ボタンなし、既存の動画状態説明|サーバー分岐テスト|
|今回の失敗/timeout/取消/非対応|通常動画を維持、再試行は手動|ブラウザー失敗状態＋既存client timeoutテスト|

保存カード・比較・アップロード経路への変更なし。製品表示の終了状態がS3/LLMの終端状態を変える結合は追加していない。

## 管理側の設定

診断用 `POSE_DISPLAY_DIAGNOSTIC_*` とは独立。すべてサーバー専用でNEXT_PUBLICは使わない。設定変更後はProductionを再デプロイし、開いている履歴を再読み込みする。

|設定|限定公開|全体公開|OFF|
|---|---|---|---|
|POSE_VIEWER_ENABLED|`true`|`true`|削除または`false`|
|POSE_VIEWER_AUDIENCE|`allowlist`（未設定でも同じ）|`all`|削除可|
|POSE_VIEWER_USER_IDS|対象の本人ID、複数ならカンマ区切り|削除可|削除可|

限定公開: 既存の診断用allowlistで確認済みの本人IDを管理画面で転記する。IDを文書/agmsgへ貼らない。空のallowlistは全員拒否、部分一致・wildcardは使わない。不正なaudienceは拒否。対象者は履歴で新しい操作が見え、対象外は従来の動画だけであることを確認する。

全体公開: **T12-2e後の公開判断を受けてから**audienceをallへ変更し再デプロイ。全体公開でも認証済み本人の所有動画に限る。

OFF: enabledをfalseへ変更し再デプロイ。履歴を再読み込みすると従来の動画表示だけに戻る。既に開いた画面のWorkerをサーバー設定変更だけで即座に停止するものではないため、本人は「表示を終了」して再読み込みする。診断ルートは当面維持し、撤去判断はT12-2e後。

## 依頼者のiPhone確認（検収・限定デプロイ後）

1. SafariまたはChromeでログインし、自分の動画の履歴詳細を開く。いつもどおり動画とAI分析が見られることを確認する。
2. 「骨格と数値を表示」を押す。取得中の案内が出て、取得後に「計測を開始」が出れば正常。保存済みカードで計測不能の履歴では入口が「検出できた部分を見る」になる。
3. 「計測を開始」を押す。準備中の枚数が増え、完了すると骨格が映像の人物に重なり、動画の下に膝・腰の現在値が出る。「—」は計測できない値であり0点ではない。
4. 再生・一時停止・シーク、0.1秒前/先、再生速度変更を試す。別の時刻の骨格が残らず、再生/計測時刻と数値が更新されれば正常。スマホを横向きにして戻しても骨格が映像に重なること、画面が横にはみ出さないことを確認する。全画面や小窓再生では動画だけ、元の画面へ戻ると骨格を再表示する。
5. 「骨格を隠す」→「骨格を再表示」で再計測せず表示が戻ることを確認。「表示を終了」では骨格と今回の数値が消え、動画の再生とAI分析の閲覧を続けられることを確認する。再表示は取得からやり直す。
6. 準備中に「表示を終了」を押す。後から古い骨格が出てこないことを確認する。再度始めたら、iPhoneの画面下から上へスワイプしてホーム画面へ戻り、5秒待ち、Safari（Chromeで試していたらChrome）のアイコンを押す。骨格表示を終了した案内が出て、古い骨格・数値がなく、勝手に計測を再開しなければ正常。
7. 履歴一覧へ戻って同じ動画を開き直す。前の骨格が残っていないこと、フォーム計測カードの登録時結果が変わっていないことを確認する。

端末/ブラウザと、どの操作で何が見えたかを報告する。T12-2bのブラウザ名は確認中なので今回明記する。元MOVと20秒近い実撮影動画は未検証・保留（素材待ち、依頼者判断2026-10-06）。用意できたら[T11-7e共通素材手順](t11-7e-release-gate.md)でアップロード後の同じ履歴を使う。これらの実機試験やT12-2e負荷判定をローカル検証で合格扱いにしない。
